# 🥚 Smart Egg Incubator

A simple Python simulation of an automated egg incubator.

## Features

- Temperature Monitoring
- Humidity Monitoring
- Heater Control
- Cooler Control
- Fan Control
- Humidifier Control

## Technologies

- Python 3

## Run

```bash
python incubator.py
```

## Output

```
===== Smart Egg Incubator =====

Temperature: 37.8 °C
Humidity: 58 %

Temperature Stable
Humidity Stable
```
